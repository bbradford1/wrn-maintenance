WRN maintenance folder pilot — 2026-10-27

Extract ZIP on Windows and upload its individual top-level files to GitHub together (not ZIP). No GitHub updates have been made automatically.

FIRST WRN (Ubuntu 22.04, ordinary wave user):
wget -qO- https://raw.githubusercontent.com/bbradford1/wrn-maintenance/main/installer.sh | bash
cd ~/Downloads/maintenance
sudo bash wrn_maintenance.sh --diagnose
sudo bash wrn_maintenance.sh --preview
sudo bash wrn_remaining_os_space.sh

Fetch three text reports from /home/wave/Downloads/maintenance through Cockpit. Do not apply or delete until reports reviewed. No screenshot required.

NOTE: installer pinned hashes apply to these exact bundle versions. Upload all files together or downloads fail verification. Do not upload customer reports.

Cleanup after verification:
cd ~/Downloads/maintenance && sudo bash wrn_downloads_cleanup.sh --preview
cd ~/Downloads/maintenance && sudo bash wrn_downloads_cleanup.sh --delete

Unrelated Downloads data and the maintenance folder itself are preserved. Older field scripts manually downloaded to ~/Downloads are not automatically moved.
